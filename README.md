# One Star, Five Stars for the Food

An alien tourist leaves planet Earth a furious one-star review — the saucer
got towed, the rain falls without permission, and a local held eye contact
for a full nine seconds — yet still has to admit, through gritted mandibles,
that the tacos deserve five stars and reformatted all three of its stomachs.

## How it works

`main.py` is a program/v1 entrypoint (Python standard library only,
deterministic, offline). It writes exactly one sentence — the review above,
196 characters — to `/output/entry.txt`, satisfying the gate: UTF-8 text of
1 to 200 characters, not only whitespace, a single sentence. Run it with:

```sh
python3 main.py
```

Running it any number of times produces byte-identical output.
